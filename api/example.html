GitWay API Example

1. Basic API Usage

Initialize the GitWay API client and fetch status:

const client = new GitWayClient({ baseUrl: 'https://teslasolar.github.io/gitway', version: 'v1' }); // Get API status const status = await client.getStatus(); console.log(status);

2. Available Endpoints

The GitWay API provides these static JSON endpoints:

/api/v1/status.json - API status and information
/api/v1/config.json - Configuration settings
/api/v1/components.json - Available components
/api/v1/collections.json - Data collections
/api/v1/manifest.json - API manifest

3. Fetch Components

Get information about available GitWay components:

const components = await client.getComponents(); components.components.forEach(comp => { console.log(`${comp.name} - ${comp.description}`); });

4. Polling for Updates

Poll an endpoint for changes:

const pollId = client.pollEndpoint('status.json', (error, data) => { if (error) { console.error('Poll error:', error); } else { console.log('Updated data:', data); } }, 5000); // Poll every 5 seconds // Stop polling client.stopPolling(pollId);

5. Auto-Initialize with Data Attributes

You can auto-initialize the client using HTML data attributes:

<div data-gitway-api="https://teslasolar.github.io/gitway" data-gitway-version="v1" data-gitway-cache-timeout="60000" data-gitway-websocket="ws://localhost:3001" data-gitway-container="app"></div>

6. Direct API Access

You can also access the API directly without the client library:

// Using fetch directly fetch('https://teslasolar.github.io/gitway/api/v1/status.json') .then(response => response.json()) .then(data => console.log(data)); // Using XMLHttpRequest const xhr = new XMLHttpRequest(); xhr.open('GET', 'https://teslasolar.github.io/gitway/api/v1/config.json'); xhr.onload = () => console.log(JSON.parse(xhr.responseText)); xhr.send();

7. CORS-Enabled Access

The API can be accessed from any domain (CORS-enabled):

// From any website or application const response = await fetch('https://teslasolar.github.io/gitway/api/v1/manifest.json'); const manifest = await response.json(); console.log('GitWay API Version:', manifest.version);

Try it from browser console on any website!
