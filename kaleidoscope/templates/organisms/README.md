# Organisms - Full Page Templates

**Organisms are complete, parameterized page layouts**

## Templates
- **oee-dashboard** - OEE metrics, trends, pareto
- **industry-page** - Universal production page
- **maintenance-view** - Equipment & work orders
- **quality-control** - SPC charts & inspections
- **alarm-summary** - Alarm management page

## Usage
```json
{
  "template": "industry-page",
  "params": {
    "title": "Line 1 Production",
    "metrics": [...],
    "equipment": [...]
  }
}
```

Organisms = Full pages. Highly parameterized. No hardcoding.
